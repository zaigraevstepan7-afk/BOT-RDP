# Reality (VLESS + XTLS-Vision)

Набор файлов для поднятия Xray Reality на своём VPS и подключения клиента.
Маскировка под `ya.ru`, порт `443`. Скрипты неразрушающие: если `443` занят —
установка останавливается и ничего не ломает, SSH (22) не трогается.

## Файлы

| Файл | Где запускать | Назначение |
|------|---------------|------------|
| `server-quick-install.sh` | на сервере, root | быстрая установка — вставить содержимое целиком в консоль |
| `reality-setup.sh` | на сервере, root | то же, но отдельным скриптом: `sudo bash reality-setup.sh` |
| `client-reality-full.json` | на клиенте (Xray) | весь трафик через прокси |
| `client-reality-split.json` | на клиенте (Xray) | RU-домены/IP идут напрямую, остальное через прокси |

## Установка на сервере

1. Зайти root'ом (консоль провайдера или SSH-приложение вроде Termius).
2. Один из вариантов:
   - вставить целиком содержимое `server-quick-install.sh`, **или**
   - залить `reality-setup.sh` и выполнить `sudo bash reality-setup.sh`.
3. Дождаться строки вида `OK ... Reality ... :443 (sni=ya.ru)`.
4. **Открыть порт `443/tcp` в облачном фаерволе провайдера** (не только в ufw).

Перед запуском стоит проверить, что порт свободен:

```bash
ss -tlnp | grep ':443 '
```

## Клиент

Импортировать `client-reality-split.json` (рекомендуется) или
`client-reality-full.json` в Xray-клиент. Локальные прокси после старта:

- SOCKS5: `127.0.0.1:10808`
- HTTP:   `127.0.0.1:10809`

## Идентичность

Серверный `privateKey` и клиентский `publicKey` — согласованная пара; UUID,
`shortId` и SNI совпадают во всех файлах.

## ⚠️ Безопасность

Эти файлы содержат `privateKey` и UUID сервера. Они попадают в git-историю.
Если репозиторий станет публичным или ключи утекут — перегенерируй пару ключей
(`xray x25519`), UUID и `shortId`, обнови конфиги на сервере и клиенте.
